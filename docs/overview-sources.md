# Overview copy sources

Drafted 2026-11-10 at the user's request from the following public sources. Copy is paraphrased, with clinical translation framed as a goal rather than an established service or outcome.

- https://rcnl.rice.edu/ — lab name and vision.
- https://rcnl.rice.edu/research.html — historical project examples: post-stroke gait rehabilitation, pelvic sarcoma surgery and rehabilitation, knee osteoarthritis/joint mechanics, and human motion measurement. These are not labeled as currently funded projects in the Overview copy.
- https://github.com/rcnl-org — repository types and invitation to contribute, report issues, or request features.
- https://github.com/rcnl-org/nmsm-core — toolset structure and OpenSim/MATLAB foundation.
- https://nmsm.rice.edu/ — NMSM Pipeline purpose and data modalities.
- https://nmsm.rice.edu/getting-started/intro/ — personalization and treatment optimization workflow.
- https://nmsm.rice.edu/guides-and-publications/tool-overviews/model-personalization/ — individual joint, muscle-tendon, neural control, and ground contact parameters.
- https://nmsm.rice.edu/guides-and-publications/tool-overviews/treatment-optimization/ — tracking, verification, and design optimization.

The two-step explanation is an editorial simplification of the documented toolsets, not a claim that clinical decision-making requires only two steps. No new efficacy, clinical availability, funding, or quantitative outcome claims were added.
